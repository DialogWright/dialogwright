# DialogWright brand assets

| File | Use |
|---|---|
| `dialogwright-logo.svg` | Horizontal logo, for light backgrounds |
| `dialogwright-logo-dark.svg` | Horizontal logo, for dark backgrounds (white wordmark) |
| `dialogwright-mark.svg` | The mark alone, square, for light backgrounds |
| `dialogwright-mark-dark.svg` | The mark alone, square, for dark backgrounds |
| `favicon.svg`, `favicon-32.png`, `favicon-180.png`, `favicon-512.png` | Browser tab, Apple touch icon, large icon (transparent) |
| `avatar-navy-512.png`, `avatar-white-512.png` | Profile pictures with a solid background (GitHub, npm, social) |

Colors: teal `#009DA0`, navy `#1E2B79`.

The mark is a speech bubble whose lower edge is a W. The wordmark is Plus Jakarta Sans ExtraBold
(SIL Open Font License 1.1), converted to outlines. `build.mjs` regenerates the SVGs.

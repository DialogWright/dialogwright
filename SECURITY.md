# Security policy

DialogWright is software that decides what an agent is allowed to do, so security reports matter.

## Reporting a vulnerability

Please report vulnerabilities privately. On this repository, open the Security tab and choose "Report a vulnerability" (a GitHub security advisory). Do not open a public issue for a security problem.

Include as much of the following as you can:

- What the problem is and which component it affects
- Steps or a minimal example to reproduce it
- The version or commit you tested
- The impact: what an attacker could do, and under what conditions
- Any suggested fix

You will get an acknowledgement, and we will keep you informed as we investigate and fix the problem. Please give us a reasonable chance to release a fix before you disclose it publicly.

DialogWright is pre-release, and only the latest commit on `main` is supported.

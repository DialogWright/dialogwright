Read this page whole at step 2: for each decision the worksheet asks ([worksheet.md](worksheet.md#decisions)), find its row and read the pattern it names (the YAML, the scripted calls that test it, the pitfall). Open the guide section a row names when the pattern leaves a question open, one section at a time: the guide is too long to read whole. SKILL.md's steps name the few sections each step reads anyway.

## Defaults for a new app

What the skill sets on every new app unless the paragraph says otherwise, and what it recommends. Write each choice in the worksheet.

| Setting | The skill's choice | Why |
|---|---|---|
| `handoff.data.unconfirmed` (app.yaml) | `mark` | the person taking the call sees which values the caller never confirmed; the engine's default, `send`, names none |
| An emergency or safety intent | `priority: { correctsForm: true }` | acted on mid-form, and the handoff carries the value the caller's switching words gave |
| An answer that ends the call or turns a caller away | **recommended**: read it back (`confirmValues`, `confirm: always` or the check's `confirm`) | a misheard answer would end a call the business wanted; leave it out only where the paragraph says so, and write the choice |
| A form that rules callers out | one form with checks, qualifying slots first | it keeps what the caller says up front; `next` only for several roads to one booking |
| An offer of the caller's number | required (`onNo: ask`, `ifNone: ask`) unless a no means "don't" | a required value is never skipped by accident |
| An offer's answers | `yes-no-or-value` unless its line asks only a yes or no question | a value said is then taken as meant |
| `unsureIntent`, `changeSlotWithValue`, `anythingElseSilence`, thresholds, `BARGE_IN` and the timings | the engine's defaults | change one only for a reason the paragraph or a recording gives |

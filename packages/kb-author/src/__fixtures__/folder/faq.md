# Borrowing

You can borrow up to **20 items** at a time with an [adult card](https://library.example/cards).

## How long can I keep a book?

Books are lent for *three weeks*. DVDs are lent for `one week`.

- Renew online
- Renew at any branch desk

## Lost cards

Report a lost card at any branch desk; a replacement is free.

Returns
-------

Items can be returned at any branch, or in the return box outside the main branch.

```
Return box: open all day
```

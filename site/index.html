Voice and chat agents that understand people like an LLM, and act like code.

Callers say it their own way. A decision model works out what they mean, your code decides what happens, and they hear the words you approved. What is said and done is predictable, and replies are fast.

Decision models are the heart of it

A decision model reads what the caller said and answers typed questions: yes or no (a noul), which option (a choice), how much (a score), each with a probability. It never writes text. DialogWright asks all of a turn's questions in one request, and code acts on the answers with thresholds the app sets.

Jev is the default, TypeSafe's decision model (jev-1.13). Any model that speaks the same System One API can replace it, measured on the app's own recorded calls, as Microsoft-Decision-1 has been.

Why it is cheap: it writes no text, only a few probabilities, so a turn pays almost only for reading.

Why you would use it

  • Callers talk naturally. Their own words, three answers at once.
  • What is said and done is predictable. Approved lines, steps decided by code.
  • Fast and cheap per turn. A turn's answers in about 90 to 150 ms (p50).
  • Every decision is audited. Allowed or refused, hash-chained.
  • Tested with recorded calls and an adversarial suite.
  • Runs on your own machine, scales to High Availability. Servers share one database; a call is taken over when its server stops.
  • Built for AI coding assistants: Claude Code builds the app.
  • Generated wording only where you opt in. The front desk's read-back: a fixed line, a checked summary, the caller's exact words if a check fails.

Describe your line in a paragraph. Claude Code builds the app.

DialogWright ships a Claude Code skill, create-app, in every project npm create dialogwright makes. Say what callers can ask for, who must verify, what must be confirmed and what goes to a person. Claude Code plans the app, scaffolds it, writes the YAML, the code, the corpus and the scripted calls, and works until the checks, the type check, the tests and the stub regression are green. Then it hands you the recording command, and triages the recording.

The utility and the front desk were each built this way, from one paragraph.

Quick start

Node 22.19 or later and pnpm. No keys: each app answers from its own labelled examples.

  1. Clone and install.

    git clone https://github.com/DialogWright/dialogwright.git
cd dialogwright
pnpm install

  2. Talk to the clinic in a text console.

    pnpm --filter @dialogwright/example-clinic cli --client heuristic

  3. Start an app of your own.

    pnpm create-app <name>

A real phone line needs a carrier account and a decision model's key (and a render model's for generated wording): run it on a machine you own.
